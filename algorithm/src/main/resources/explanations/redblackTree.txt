  <h2 style="color:#2b4a6f;text-align:center;">Understanding Red-Black Trees</h2>

  <p>
    A <strong>Red-Black Tree (RBT)</strong> is a self-balancing binary search tree where each node contains an extra bit representing its <em>color</em> (red or black).
    RBTs maintain balance using the following properties:
  </p>
  <ul>
    <li>Every node is either red or black.</li>
    <li>The root is always black.</li>
    <li>All leaves (null nodes) are black.</li>
    <li>Red nodes cannot have red children (no two reds in a row).</li>
    <li>Every path from a node to its descendant leaves contains the same number of black nodes.</li>
  </ul>

  <h3 style="color:#2b4a6f;">Add Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Time Complexity:</strong> O(log n)
  </p>
  <p><strong>Goal:</strong> Insert a new value while maintaining BST order and Red-Black properties.</p>
  <ol>
    <li>Insert the node as in a standard BST and color it red.</li>
    <li>Check Red-Black properties and fix violations using rotations and recoloring:
      <ul>
        <li>Case 1: Parent is black → nothing to do.</li>
        <li>Case 2: Parent and uncle are red → recolor parent, uncle, and grandparent.</li>
        <li>Case 3: Parent is red but uncle is black → perform rotations (left, right, or combination) and recolor.</li>
      </ul>
    </li>
    <li>Ensure the root remains black.</li>
  </ol>

  <h3 style="color:#2b4a6f;">Find Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Time Complexity:</strong> O(log n)
  </p>
  <p><strong>Goal:</strong> Search for a value in the tree.</p>
  <ol>
    <li>Start at the root.</li>
    <li>If the target equals the current node's key, it is found.</li>
    <li>If the target is smaller, search recursively in the left subtree; if larger, search the right subtree.</li>
    <li>If a null node is reached, the value does not exist in the tree.</li>
  </ol>

  <h3 style="color:#2b4a6f;">Remove Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Time Complexity:</strong> O(log n)
  </p>
  <p><strong>Goal:</strong> Delete a node while maintaining BST order and Red-Black properties.</p>
  <ol>
    <li>Remove the node as in a standard BST:
      <ul>
        <li>Node with 0 or 1 child → delete directly.</li>
        <li>Node with 2 children → replace with in-order successor and delete successor.</li>
      </ul>
    </li>
    <li>If the deleted node or replacement was black, fix Red-Black violations using rotations and recoloring:
      <ul>
        <li>Double-black cases are resolved using sibling color checks, rotations, and recoloring.</li>
      </ul>
    </li>
    <li>Ensure the root remains black.</li>
  </ol>
