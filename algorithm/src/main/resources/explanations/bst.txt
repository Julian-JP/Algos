  <h2 style="color:#2b4a6f;text-align:center;">Understanding Binary Search Trees</h2>

  <p>
    A <strong>binary search tree (BST)</strong> is a hierarchical data structure in which each node has at most
    two children, called <em>left</em> and <em>right</em>. The tree satisfies the
    <strong>binary search property</strong>: for any node, all keys in its left subtree are smaller, and all keys in its right subtree are larger.
  </p>

  <p>
    This property allows efficient searching, insertion, and deletion of elements while keeping the data sorted.
  </p>

  <h3 style="color:#2b4a6f;">Add Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Average Time Complexity:</strong> O(log n) &nbsp;&nbsp; | &nbsp;&nbsp; <strong>Worst Case:</strong> O(n)
  </p>
  <p><strong>Goal:</strong> Insert a new value while maintaining the BST property.</p>
  <ol>
    <li>Start from the root.</li>
    <li>If the new value is smaller than the current node, go to the left child; otherwise, go to the right child.</li>
    <li>Repeat until a null child is reached.</li>
    <li>Insert the new node in that position.</li>
  </ol>

  <h3 style="color:#2b4a6f;">Find Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Average Time Complexity:</strong> O(log n) &nbsp;&nbsp; | &nbsp;&nbsp; <strong>Worst Case:</strong> O(n)
  </p>
  <p><strong>Goal:</strong> Search for a specific value in the tree.</p>
  <ol>
    <li>Start at the root node.</li>
    <li>If the target value equals the node’s key, the element is found.</li>
    <li>If the target is smaller, search recursively (or iteratively) in the left subtree; otherwise, in the right subtree.</li>
    <li>If a null node is reached, the value does not exist in the tree.</li>
  </ol>

  <h3 style="color:#2b4a6f;">Remove Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Average Time Complexity:</strong> O(log n) &nbsp;&nbsp; | &nbsp;&nbsp; <strong>Worst Case:</strong> O(n)
  </p>
  <p><strong>Goal:</strong> Delete a value while maintaining the BST property.</p>
  <ol>
    <li>Find the node to be removed using the search process.</li>
    <li>If the node has no children, simply delete it.</li>
    <li>If the node has one child, replace it with its child.</li>
    <li>If the node has two children:
      <ul>
        <li>Find its <strong>in-order successor</strong> (smallest value in the right subtree).</li>
        <li>Replace the node’s key with the successor’s key.</li>
        <li>Delete the successor node from the right subtree.</li>
      </ul>
    </li>
  </ol>
