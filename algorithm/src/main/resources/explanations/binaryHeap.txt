  <h2 style="color:#2b4a6f;text-align:center;">Understanding Binary Heaps</h2>

  <p>
    A <strong>binary heap</strong> is a complete binary tree that satisfies the <em>heap property</em>:
    in a <strong>min-heap</strong>, every node’s key is smaller than or equal to its children’s keys.
    The smallest element is always at the root.
  </p>

  <h3 style="color:#2b4a6f;">Insert Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Time Complexity:</strong> O(log n)
  </p>
  <p><strong>Goal:</strong> Add a new element while maintaining the heap property.</p>
  <ol>
    <li>Insert the new element at the <em>next available position</em> (the end of the heap array).</li>
    <li><strong>Bubble up</strong> — compare it with its parent and swap if smaller.</li>
    <li>Repeat until the heap property is restored.</li>
  </ol>

  <h3 style="color:#2b4a6f;">DeleteMin Operation</h3>
  <p style="font-size:0.95em;margin-top:-8px;margin-bottom:10px;color:#666;">
    <strong>Time Complexity:</strong> O(log n)
  </p>
  <p><strong>Goal:</strong> Remove the smallest element (the root) while maintaining the heap property.</p>
  <ol>
    <li>Remove the root (minimum element).</li>
    <li>Move the last element in the heap to the root position.</li>
    <li><strong>Bubble down</strong> — compare with its smaller child and swap if larger.</li>
    <li>Repeat until the heap property is restored.</li>
  </ol>
